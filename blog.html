Question-1: What are the different ways to select an element in the DOM?

There are several ways to select elements in the DOM by using JavaScript. Here are some of them given below:
1. document.getElementById()
2. document.getElementsByClassName()
3. document.getElementsByTagName()
4. document.getElementsByName()
5. document.querySelector()

Question-2: What is the difference between innerHTML, innerText, and textContent ?

Here is the short answer below:
1. innerHTML: Works with the HTML contents of an element.
2. innerText: Works with the text contents of an element.
3. textContent: Works almost same as innerText but also includes hidden text contents.

Question-3: What is event delegation in the DOM?

Event delegation is a technique where we add an event listner directly to a parent instead of each child elements.

Question-4: What is event bubbling in the DOM?

Event bubbling in the DOM is something like we click on a button inside a div, then it triggers to its parent then grandparent and goes on up to document.

Question-5: How do you create, add, and remove elements using JavaScript?

Here are the simple ways to do these:
1. To creat element: document.creatElement()
2. To add element: appendChild()
3. To remove element: removeChild()
